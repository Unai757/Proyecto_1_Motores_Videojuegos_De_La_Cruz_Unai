# Proyecto 1: Motores de Videojuegos (De La Cruz, Unai)

### Práctica del Tema 1

En esta práctica empezamos a trabajar con el entorno de Godot, probando a crear escenas y a gestionar el proyecto con Git, entre otras cosas.

Para este proyecto he seleccionado dos *assets* (uno de un samurái viejo y otro de un gato), ya que me gustaba mucho su estilo visual.

Además, se han creado escenas, se han configurado las teclas para el movimiento de los personajes y se ha organizado la estructura de carpetas de un proyecto en Godot.
